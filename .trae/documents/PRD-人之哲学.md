## 1. 产品概述

将我们关于"人是否描述活着的状态"这一哲学讨论转化为一个沉浸式、交互式的前端页面，以视觉化的方式呈现从生物学、哲学、法律、现象学、东方哲学、科幻等多个角度的思考。

- 目标用户：对哲学、语言、存在主义感兴趣的思考者与阅读者
- 产品价值：将抽象的哲学对话转化为可浏览、可交互、可沉浸的视觉体验，让用户在浏览中感受思想的层次与深度

## 2. 核心功能

### 2.1 用户角色
| 角色 | 权限 |
|------|------|
| 访客 | 浏览全部内容、交互探索各哲学视角 |

### 2.2 功能模块
1. **开篇/引子**：以一个引人深思的问题开场，建立氛围
2. **十大视角呈现**：生物、日常语言、哲学、法律、社会关系、现象学、东方哲学、超人类主义、维特根斯坦、总结——每个视角以独立章节呈现
3. **交互式探索**：用户可以点击/滚动深入每个视角的细节
4. **视觉主题**：哲学沉思氛围，深色背景配合文字艺术

### 2.3 页面详情
| 页面 | 模块 | 功能描述 |
|------|------|----------|
| 单页应用 | Hero 开屏 | 大标题 + 核心问题，氛围感开场动画 |
| 单页应用 | 视角章节 | 10个哲学视角，每个有独立的视觉风格和过渡动画 |
| 单页应用 | 交互元素 | 引用展开、思想实验卡片、对比视图等 |
| 单页应用 | 结尾总结 | 表格汇总所有视角的答案，引导用户思考 |

## 3. 核心流程

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**：深邃墨黑 (#0a0a0f) 搭配 暖金 (#c9a94e) 与 暗红 (#8b2f3a)
- **氛围**：哲学沉思、图书馆质感、暗色调 + 微光效果
- **字体**：衬线字体展现哲学感，标题用粗犷的展示字体
- **按钮风格**：极简，无边框，悬停时暖金发光
- **布局**：全屏章节滚动，每章一个"场景"
- **动画**：滚动触发内容浮现，文字渐入，视差效果，粒子或噪点纹理背景

### 4.2 页面设计概览
| 章节 | 视觉元素 |
|------|----------|
| Hero 开屏 | 居中的核心问题大字，背景暗调纹理，缓慢呼吸动画 |
| 生物学视角 | 冷静、理性风格，DNA 双螺旋抽象图形 |
| 日常语言视角 | 温暖、人文感，文字引用卡片堆叠 |
| 哲学经典视角 | 学院风格，亚里士多德/洛克头像剪影 |
| 法律视角 | 严肃、结构化，条款式排版 |
| 社会关系视角 | 网状关系图，渐变过渡 |
| 现象学视角 | 诗意的，大字"向死而生"，时间线 |
| 东方哲学视角 | 水墨/书法质感，留白，禅意 |
| 科幻视角 | 霓虹/赛博朋克风格，发光边框 |
| 维特根斯坦视角 | 网状节点，"家族相似"可视化 |
| 总结 | 表格 + 开放性问题 |

### 4.3 响应式
- 桌面优先设计
- 适配平板和手机

## 5. 开发约束
- 纯前端单页应用，无需后端
- 使用 React + Vite
- 不使用 Tailwind，使用纯 CSS 实现设计效果
- 所有内容来自我们的对话，无需外部数据

# 彻底消除背景图水印（V2）

## 方案

遮罩保持 75% 不变，只调整背景图的缩放和定位，把右下角水印推出可视区域。

放大到 **150%** + 焦点上移到 **10%** 位置，使底部约 40% 区域被裁切，水印彻底消失。

### 改动文件

| 文件 | 行 | 当前值 | 改后值 |
|------|:--:|:------:|:------:|
| `ChapterSection.css` | 23-24 | `115%` / `50% 25%` | **`150%` / `50% 10%`** |
| `HeroSection.css` | 25-26 | `115%` / `50% 30%` | **`150%` / `50% 15%`** |
| `SummarySection.css` | 27-28 | `115%` / `50% 25%` | **`150%` / `50% 10%`** |

遮罩全部不动，保持 `rgba(0, 0, 0, 0.75)`。

## 验证

- `npm run check` 编译通过
- 刷新页面，确认所有背景图底部无法看到水印字样
- 检查图片主体是否仍能提供氛围感（抽象图缩放 150% 影响较小）
